Prex Surprise Calls

A site that makes ordering a surprise call feel like part of the surprise.

The brief
A launching business that phones someone with your personal message and sends you the recording. The first design draft felt plain and generic, so I rebuilt it around smooth motion and a warm pink and peach look, using only real information.
What I built
  • A booking form that opens WhatsApp with the order already written out
  • A scroll-and-tap date and time picker, so nobody types a date
  • An admin dashboard with a visitor counter
  • A proper image preview when the link is shared on WhatsApp
Built with
HTML, CSS and JavaScript, Firebase, Netlify

Client project · Community platform

Epiphany Hub

A home and a front door for a community that had outgrown its WhatsApp groups.

The brief
Epiphany Hub is a 300-member community across Nigeria, Ghana, Cameroon and the UK. It needed a multi-page site, a better way to join than a Google Form, and a way to grow into smaller circles led by real people.
What I built
  • A multi-page site with six community rooms and a tab switcher
  • A join flow that saves sign-ups to Firestore, built around what people are here for
  • An admin dashboard to manage sign-ups
  • Testimonials that only go live after an admin approves them
Built with
HTML, CSS and JavaScript, Firebase (Firestore), Netlify
